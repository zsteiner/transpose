## Project Overview

Transpose is a music transposition tool built with **Next.js 16** (App Router), **React 19**, **TypeScript 5**, and **XState 5**. It helps musicians transpose notes, scales, chords, and custom notation between instruments using circle of fifths arithmetic.

## Commands

```bash
npm run build            # Production build
npm run lint             # ESLint + Stylelint

npm run test:unit:watch  # Jest in watch mode
npm run test:e2e         # Playwright e2e tests
npm run test:e2e:headed  # Playwright with browser visible
npm test                 # Unit + e2e tests
```

## Architecture

### Core Concept: Circle of Fifths

Notes are positions 0–11 on the circle of fifths (0=C, 1=G, 2=D, ..., 11=F). Transposition formula: `(position + factor) % 12`. Each instrument has a `transposeFactor` (its offset from concert pitch C). The transpose factor between two instruments is `instrument2.transposeFactor - instrument1.transposeFactor`.

**Important:** Circle of fifths positions are NOT semitones. Use `circleFifthsPositionToSemitones()` when converting for notation rendering (ABCJS).

### State Management (XState 5)

`src/components/useTranspose/machine.ts` — Central state machine holding `originalNote`, `instrument1`, `instrument2`, with `transposeFactor` and `transposedNote` derived automatically. Components access state via `useTranspose()` hook, never by calling utility functions directly.

### Key Data Flow

1. **Machine** stores state and derives transposition results
2. **`useTranspose()` hook** exposes state and event dispatchers to components
3. **`UrlSyncWrapper`** keeps URL params (`?note=C&instrument1=piano&instrument2=clarinet`) in bidirectional sync with machine state
4. **Components** read from hooks and dispatch events — no direct state mutation

### Pages (App Router)

- `/` — Single note transposition with interactive circle of fifths
- `/scales` — Scale transposition
- `/chords` — Chord transposition
- `/custom` — Custom ABC notation input and transposition

### Key Directories

- `src/components/useTranspose/` — XState machine, provider, and hook
- `src/utils/` — Pure functions: `transposeNote`, `transposeNoteList`, `writeNotation`, `circleFifthsPositionToSemitones`
- `src/constants/` — Static data: notes, instruments, scales, chords, ABC notation config
- `src/types.ts` — Shared TypeScript types
- `e2e/` — Playwright tests

### Notation Rendering

Uses **abcjs** library to render sheet music. ABC notation strings are generated by `src/utils/writeNotation.ts`. The `ReactAbc` component wraps the library for React integration.

## Conventions

- **CSS Modules** with CSS custom properties for theming (dark mode via `prefers-color-scheme`)
- **Stylelint** enforces alphabetical CSS property ordering
- **Prettier**: single quotes, trailing commas, 80 char width, single attribute per line
- **Path alias**: `@/*` maps to `./src/*`
- **React Compiler** is enabled — avoid patterns that break compiler assumptions
- Use `transposeNoteList()` for multiple notes, not looping `transposeNote()`
- Dispatch events through the machine/hooks, don't manually compute transposition in components

## Testing

- **Unit tests** (`*.test.ts` in `src/`): Pure utility functions and machine logic
- **E2E tests** (`e2e/`): Playwright on Chromium; uses a hydration helper in `e2e/helpers.ts` to wait for React
- CI runs lint, unit tests, and e2e tests on PRs to main
